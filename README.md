# LangChain SQL Agent with Azure OpenAI

A **Streamlit** application that allows users to query a **PostgreSQL** database using **natural language**. The app leverages **LangChain** and **Azure OpenAI** to generate optimized SQL queries and execute them.

## 🚀 Features

- **Natural Language to SQL**: Ask questions in plain English and get SQL queries.
- **Query Execution**: Run generated SQL queries directly in the app.
- **Chat History**: Maintains conversation context during the session.
- **Optimized Queries**: The agent generates optimized SQL queries for your questions.

---

## 📋 Prerequisites

- **Python 3.8+**
- **PostgreSQL** (or another supported SQL database)
- **Azure OpenAI API access**
